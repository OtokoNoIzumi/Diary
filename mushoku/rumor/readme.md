# 原作查证

网页对外的名字是「原作查证」。页面是 `mushoku/index.html`，GitHub Pages 上打开 `mushoku/` 即可。现有条目是示例。

## 文件

| 文件 | 作用 |
| --- | --- |
| `../index.html` | 目录、短列表、完整记录、轮播、已读、维护窗口 |
| `rumor-data.js` | 目录和全部条目 |
| `rumor-share.js` | 把一条记录画成图片。微信里弹出长按保存，电脑上复制或下载 |
| `qrcode.js` | 二维码只画进分享图 |

分享图的做法来自已有的海报模块：先画一张固定宽度的离屏卡片，再变成图片，按环境交出。图片路径写在条目里。零食素材库那种本地目录授权没有放进这一页。

## 一条记录

编号创建后固定。不要手写下一个号。页面底部「维护」会取当前最大号加一，下载一份新的 `rumor-data.js`，用它替换本目录里的同名文件。

| 字段 | 含义 |
| --- | --- |
| `category` | `canon` 原作，`anime` 动画，`study` 考据，`other` 其他。不实在记录性质里，内容里不单列谣言 |
| `verdict` | `true` 属实，`false` 不实，`open` 未定性。决定卡片颜色 |
| `claim` | 流传的那句话，或要查的疑点 |
| `summary` | 一句结论 |
| `details` | 展开 |
| `comparisons` | `{ source, text }` 的数组。日文、译本、镜头、推特都可以 |
| `images` | `{ src, caption }`。`src` 相对 `mushoku/index.html` |
| `see` | 相关编号 |

`chapters`、`characters`、`others` 只能填目录里的 id。角色名单是要覆盖的范围，没有条目也显示 0。

没点某一行的标签时，这一行不筛，等于「全部」。点标签是选中，同一行里多选是「或」；行与行之间是「并且」。点「全部」只把这一行收回不筛。数字会跟着当前条件变。

## 已读

点开一条、点相关编号、或点「生成分享图」才记已读。轮播自己换页不算。分母是现在的条数。上次打开后多出来的编号会标成新增。

## 分享图

记录页上没有二维码。分享图里有关注点、结论、展开、对照和配图。点「生成分享图」后：电脑会下载图片并复制到剪贴板；手机交给系统分享；微信里弹出图片，长按保存。配图先读成页内数据再画；读不到时这张图仍会生成，只是不带那张配图。
