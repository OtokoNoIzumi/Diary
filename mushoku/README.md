## 产出管线说明

### Markdown 层（源文件）
- `discussion.md`：论证骨架。核心论点、论证链、概念区分。所有后续产出的锚点
- `script.md`：从 discussion 派生的口播稿。带 `[画面]` / `[字幕强调]` / `[素材类型]` 标记，可直接进 TTS
- `references.md`：参考资料、Credit、吸收来源

### HTML 层（交付件）
- 双模切换页面：
用老鲁迪线的三种花做装饰
  - **PPT 展示模式**：配合视频素材的逐屏幻灯片
  - **观点索引模式**：树状层级 + 可展开/折叠的论证卡片
- 风格参考：crossgate_peribacon.html 的交互模式

### 视频层（后续）
- 脚本 → TTS 分段 → 自动字幕 → 画面匹配 → 剪辑
- 详细的自动化管线设计见 script.md 中的 segments 规划
